How does search work?

Search matches properties (YAML frontmatter + generated metadata like links, backlinks, filePath), not full text.

Use and, or, not, and parentheses to combine conditions.

Fields: any YAML key (e.g. tags, title) plus built-ins filePath, tags, links, backlinks.

Operators: = (or :), >, <, >=, <=, !=. * is a wildcard.

filePath = *.md
tags = PKSPKMS
(tags = PKSPKMS or tags = Development)
(filePath = Notes/* and filePath = *.md)
(links = * and not tags = Archive)
title = *

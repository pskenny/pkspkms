## P3 — Debt (bug-adjacent)

- `PksFile` copy constructors share nested lists (shallow copy aliasing)

- `SQLiteLuaConnector.getCache()` public — test-only access in main API
- Unbounded per-thread Lua compile caches
- Vacuous test: `testSqliteRepository` queries `TEST_DIR.resolve(...)` but the loader stores vault-relative paths —
  `rs.next()` is always false, its DB assertions never run
